# 避洪转移图审核清单（依据国家与行业规范）

本清单用于系统审核"避洪转移图"（含蓄滞洪区、防洪避险转移示意图等图纸，常见为 jpg/png/pdf 格式）。审核以《中华人民共和国防洪法》《中华人民共和国防汛条例》《蓄滞洪区运用补偿暂行办法》及《蓄滞洪区设计规范》SL 587-2012、《蓄滞洪区运用预案编制导则》《防洪预案编制导则》《水旱灾害防御应急预案编制导则》等为依据。

每个审核项包含：要素说明、规范依据、判定标准（通过/不通过的客观条件）、常见不合规情形。审核时逐图逐项核对，结果填入表格清单（模板见 SKILL.md）。

要素权重说明：
- 【关键】缺失或错误将直接影响避洪转移安全，必须整改。
- 【一般】影响规范性或可用性，建议整改。

---

## A. 基本图面要素（制图规范性）

**A1 图名与版本**
- 依据：预案附图编制惯例、SL 587-2012 制图要求
- 判定：图名明确含"XX 区域避洪/避险转移图"、含行政区划、绘制日期或版本号 → 通过；无图名或无法识别区域版本 → 不通过
- 常见不合规：图名笼统（仅写"转移图"）、无版本日期、与预案名称不一致

**A2 图例**
- 依据：地图制图通用规范、预案附图要求
- 判定：完整图例，能解释路线、安置点、危险区、预警点、责任人标注等所有符号 → 通过；关键符号无图例 → 不通过
- 常见不合规：路线/安置点符号未说明、图例与图面符号不符

**A3 指北针**
- 依据：地图制图通用规范
- 判定：标注正北方向 → 通过；缺失 → 不通过
- 常见不合规：无指北针、指北方向错误

**A4 比例尺**
- 依据：地图制图通用规范
- 判定：标注比例尺或注明"示意，非按比例" → 通过；完全无尺度参照且未声明示意 → 不通过
- 常见不合规：无比例尺且声称按比例、比例失真未声明

**A5 坐标系与高程基准**
- 依据：SL 587-2012、2000 国家大地坐标系要求
- 判定：标注坐标系（如 2000 国家大地坐标系）与高程基准 → 通过；缺失 → 一般项不通过
- 常见不合规：未标注、采用已废止基准

---

## B. 转移范围与淹没分析【关键】

**B1 受威胁区域**
- 依据：《防洪法》第二十四条、防汛预案编制要求
- 判定：明确标注洪水威胁范围/淹没范围，与预警水位对应 → 通过；无威胁范围 → 不通过
- 常见不合规：仅画路线无淹没区、威胁范围与水位脱节

**B2 水位（水位线）**
- 依据：《水旱灾害防御应急预案编制导则》、SL 587-2012
- 判定：标注警戒水位、保证水位或设计洪水位线，并附数值 → 通过；无水位线 → 不通过
- 常见不合规：有淹没区无量值、警戒/保证水位混淆

**B3 蓄滞洪区边界与口门**
- 依据：《蓄滞洪区设计规范》SL 587-2012、《蓄滞洪区运用补偿暂行办法》
- 判定：若属蓄滞洪区，标注区界、进退洪口门位置 → 通过；应标未标 → 不通过
- 常见不合规：蓄滞洪区内图件未标区界与口门

**B4 危险区分级**
- 依据：风险图编制惯例
- 判定：按淹没深度/风险分级分色标注 → 通过（一般项）；全图单色无分级 → 一般项不通过
- 常见不合规：风险无分级、颜色含义无图例

---

## C. 转移对象台账【关键】

**C1 人口与户数**
- 依据：防汛预案、人员转移避险台账要求
- 判定：标注转移总人口、涉及村组/户数，或能对应附册 → 通过；无对象数据 → 不通过
- 常见不合规：只有路线无人数、人数与台账不符

**C2 特殊人群**
- 依据：人员转移避险"应转尽转、专人帮扶"要求
- 判定：标注独居老人、留守儿童、残疾人、孕产妇等需帮扶对象位置及帮扶责任人 → 通过；应标未标 → 不通过
- 常见不合规：特殊人群无标记、无一对一帮扶标注

**C3 图册一致**
- 依据：预案一致性要求
- 判定：图上标注对象与预案附册台账一致 → 通过；矛盾 → 不通过
- 常见不合规：图上人数与台账对不上

---

## D. 转移路线【关键】

**D1 路线完整性**
- 依据：防汛预案转移要求
- 判定：每个受威胁单元均有对应转移路线 → 通过；有威胁区无路线 → 不通过
- 常见不合规：部分村组/小区无路线

**D2 路线安全性**
- 依据：SL 587-2012 转移道路要求
- 判定：路线避开洪水主流、低洼积水段、危桥险段 → 通过；穿越危险区 → 不通过
- 常见不合规：路线横穿河道、走漫水桥、经低洼段

**D3 就近原则**
- 依据：转移"就近、安全"原则
- 判定：路线走向合理、距离最短可行 → 通过（一般项）；明显绕远 → 一般项不通过
- 常见不合规：舍近求远、跨区远距离转移

**D4 不交叉不回头**
- 依据：转移组织有序要求
- 判定：多条路线无交叉、单向不折返 → 通过（一般项）；交叉/折返 → 一般项不通过
- 常见不合规：路线交叉导致人流对冲、来回折返

**D5 可达性与终点**
- 依据：SL 587-2012
- 判定：路线终点为安全区/安置点，道路等级满足通行 → 通过；终点仍在危险区 → 不通过
- 常见不合规：路线断头、终点未到安置点

**D6 备用路线**
- 依据：应急预案冗余要求
- 判定：重要/大体量转移单元有备用路线 → 通过（一般项）；无备用 → 一般项不通过
- 常见不合规：仅单一路线无备份

---

## E. 安置点与避洪设施【关键】

**E1 安置点标注**
- 依据：防汛预案、SL 587-2012
- 判定：标注集中安置点位置与名称 → 通过；无安置点 → 不通过
- 常见不合规：有路线无安置点

**E2 容量匹配**
- 依据：安置点规划要求
- 判定：安置点容量 ≥ 对应转移人数（或标注可容纳数）→ 通过；容量不足且无说明 → 不通过
- 常见不合规：容量小于转移人数、无容量数据

**E3 安全性（高程）**
- 依据：SL 587-2012 避洪设施高程要求
- 判定：安置点/避洪台高程高于设计洪水位 → 通过；位于淹没区内 → 不通过
- 常见不合规：安置点高程低于保证水位、在淹没范围

**E4 避洪台**
- 依据：SL 587-2012（蓄滞洪区内村庄）
- 判定：蓄滞洪区内村庄标注避洪台位置与高程 → 通过（关键，若适用）；应标未标 → 不通过
- 常见不合规：区内村无避洪台标注

**E5 安置点保障**
- 依据：安置点管理要求
- 判定：标注基本生活、医疗、供水等保障或接收责任人 → 通过（一般项）；无保障信息 → 一般项不通过
- 常见不合规：仅有位置无保障说明

---

## F. 预警指标体系【关键】

**F1 预警阈值**
- 依据：《水旱灾害防御应急预案编制导则》
- 判定：标注触发转移的水位/雨量/流量阈值及对应站点 → 通过；无阈值 → 不通过
- 常见不合规：只有路线无触发条件、阈值无站点

**F2 预警分级与行动**
- 依据：预警分级（蓝黄橙红）要求
- 判定：分级标注且每级对应转移行动 → 通过（一般项）；无分级或级行脱节 → 一般项不通过
- 常见不合规：分级与行动不匹配

**F3 预警发布责任**
- 依据：防汛责任制
- 判定：标注预警发布责任人与发布渠道 → 通过；缺失 → 一般项不通过
- 常见不合规：无发布责任人、渠道不明

**F4 预警—转移联动**
- 依据：预案衔接要求
- 判定：预警阈值与转移启动条件一一对应 → 通过；脱节 → 不通过
- 常见不合规：阈值到了但不启动转移

---

## G. 责任与组织体系【关键】

**G1 行政责任人**
- 依据：《防汛条例》行政首长负责制
- 判定：标注行政区/村行政首长责任人及联系方式 → 通过；缺失 → 不通过
- 常见不合规：无责任人、无联系方式

**G2 包保责任制**
- 依据：网格化包保要求
- 判定：网格化包保，标注包保责任人与范围 → 通过；未网格化 → 一般项不通过
- 常见不合规：责任未到户、无包保网格

**G3 转移责任人**
- 依据：现场转移组织要求
- 判定：每个转移单元标注现场转移组织人与联系方式 → 通过；缺失 → 不通过
- 常见不合规：现场无人负责、无电话

**G4 接收责任人**
- 依据：安置点接收要求
- 判定：安置点标注接收责任人与联系方式 → 通过（一般项）；缺失 → 一般项不通过
- 常见不合规：安置点无接收人

---

## H. 保障与应急资源【一般】

**H1 交通保障**
- 依据：转移交通保障要求
- 判定：标注转移车辆调配/集中乘车点 → 通过；缺失 → 一般项不通过
- 常见不合规：无车辆安排、无集中乘车点

**H2 物资与装备**
- 依据：防汛物资储备要求
- 判定：标注防汛物资/救援装备存放点 → 通过（一般项）；缺失 → 一般项不通过
- 常见不合规：无物资点标注

**H3 医疗救护**
- 依据：转移医疗保障要求
- 判定：标注医疗救护点/救护车辆 → 通过（一般项）；缺失 → 一般项不通过
- 常见不合规：无医疗点

**H4 通讯保障**
- 依据：应急通讯要求
- 判定：标注应急通讯方式（含断电/断网备用）→ 通过（一般项）；缺失 → 一般项不通过
- 常见不合规：仅依赖单一公网

---

## I. 一致性与时效性【关键】

**I1 与预案一致**
- 依据：预案一致性要求
- 判定：图面内容与防汛预案文字完全一致（范围、路线、责任人）→ 通过；矛盾 → 不通过
- 常见不合规：图与文不一致

**I2 时效性**
- 依据：预案动态更新要求
- 判定：图为最新版本，反映现状（新村、新路、新安置点）→ 通过；过期 → 不通过
- 常见不合规：沿用旧图、现状已变未更新

**I3 可操作性**
- 依据：预案可操作性要求
- 判定：图面清晰、要素无歧义、可现场直接使用 → 通过；模糊难用 → 一般项不通过
- 常见不合规：要素重叠看不清、标注歧义

---

## 审核结论分级

- **合格**：无【关键】项不通过，【一般】项缺失 ≤ 2。
- **限期整改**：存在【关键】项不通过，或【一般】项缺失 > 2，但可短期修正。
- **不合格**：存在重大【关键】项缺失（如 B/C/D/E/F/G 中整类缺失），无法指导实际转移。
