# Matplotlib 科学绘图

- 唯一标识：`hub-matplotlib`
- 显示名称：Matplotlib 科学绘图
- 能力摘要：使用 Matplotlib 的 Figure/Axes 模型创建可复现、可出版的静态与交互式图表，控制标注、坐标、配色、布局、导出和数据表达的准确性。

## 案例素材

1. 论文需要比较三种算法性能。该 skill 会绘制带误差条和清晰样本说明的曲线，选择色盲友好配色，并用矢量格式导出以确保印刷质量。
2. 仪表盘截图中的坐标轴误导用户。该 skill 会检查截断轴、单位、对数尺度和标注，确保图表表达真实差异而不夸大微小波动。
3. 批量实验要生成上百张图。该 skill 会封装统一主题和函数，固定图尺寸、文件名和数据版本，防止不同脚本输出格式不一致。
